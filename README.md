# The Long Roast: Lawmakers and the File They Cannot Convert

[![make.fun](https://make.fun/badge/u-swift-raven-16-the-long-roast-lawmakers-and-the-f3a3bdf7.svg)](https://make.fun/bounty/u-swift-raven-16-the-long-roast-lawmakers-and-the-f3a3bdf7)

One satirical sentence about lawmakers who regulate AI, crypto, or the
internet but cannot convert a file to PDF. Entry for the
[make.fun bounty](https://make.fun/bounty/u-swift-raven-16-the-long-roast-lawmakers-and-the-f3a3bdf7).

## How it works

`main.ts` writes a single satirical sentence (at most 320 characters) to
`/output/entry.txt`. The program takes no input, uses no network, and
contains the entry text in the source itself.

## Run

```sh
node main.ts
```

Then check `/output/entry.txt`: UTF-8 text, 1–320 characters, one sentence.
